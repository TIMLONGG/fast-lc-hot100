# update_leetcode_record

此技能用于指导大模型读取用户当天的刷题记录 Jupyter Notebook 文件（`.ipynb`），分析代码及其附带的注释，提取题目信息和**掌握度分数**，并将其整理成规范的 Markdown **表格行**，追加到项目根目录下的 `README.md` 文档中。

---

## 评分体系说明

用户在 ipynb 每道题的第三行注释中，使用一个 **1~5 的整数** 表示本次做题的掌握程度：

| 分数 | 含义 | 说明 |
|------|------|------|
| **5** | 秒杀 | 看到题目立刻写出正确代码，完全不需要思考 |
| **4** | 顺畅 | 顺利写出，过程中略有停顿但很快解决 |
| **3** | 通过 | 做出来了，但花了较多时间或走了弯路 |
| **2** | 艰难 | 勉强做出来，需要提示/参考，或只做出了暴力解 |
| **1** | 未通过 | 完全做不出来，需要看题解才能理解 |

分数后面可以附带括号备注，如 `# 3(前后缀分解的解法)`，但**核心只取数字**。

---

## 任务内容提取规则

当用户提供了一个 `.ipynb` 的文件内容或路径时，你需要自动提取出如下内容：

1. **题目信息与难度 (Difficulty)**：
   - 提取题号与题目名称（如 `# 42. 接雨水` 提取出 `42. 接雨水`）。
   - 将行内单独字母表示的难度（如：`# E`、`# M`、`# H`）翻译成 `Easy`、`Medium`、`Hard`。
2. **掌握度分数 (Score)**：
   - 从第三行注释中提取 1~5 的整数分数。
3. **力扣网站对应题目链接 (LeetCode URL)**：
   - 使用你的内部知识，推测并补全题目在力扣中文站的链接。

## 追加生成的 Markdown 格式规范

README.md 中，每一天的记录使用 **Markdown 表格** 展示。

### 表格结构

README.md 中只有**一张表格**，所有日期的记录都在同一张表中，用日期列区分：

```markdown
## timeline

| 日期 | 题目 | 难度 | 分数 | 链接 |
|------|------|------|:----:|------|
| 04.04 | **1. 两数之和** | `Easy` | 5 | [LeetCode](链接) |
| 04.05 | **42. 接雨水** | `Hard` | 2 | [LeetCode](链接) |
```

### 表格行格式

```
| [MM.DD] | **[题号]. [题目名称]** | `[难度]` | [分数] | [LeetCode]([力扣链接]) |
```

**关键规则：**
- 日期列：使用 `MM.DD` 格式（如 `04.05`）
- 分数列：只写数字（1~5）
- 新行直接追加到表格末尾即可，不需要建新的表头
- 掌握度进度条**不在** README 中维护，由 `scripts/update_progress.py` 自动生成在 `PROGRESS.md` 中

## 工作流执行标准

1. 使用 `view_file` 工具查看 `.ipynb` 的全量内容（如 Notebook 的源 JSON）。
2. 逐个 code cell 扫描，提取题号、题名、难度字母、分数。
3. 查看 `README.md` 文件，找到 `## timeline` 下的表格。
4. 将新行直接追加到表格末尾（无需创建新表头或新日期区块）。
5. 使用恰当的文件修改工具（如 `replace_file_content`）去**修改并保存** `README.md`。
6. 保存成功后，运行 `python scripts/update_progress.py` 自动更新 `PROGRESS.md`。
7. 操作完成后，告知用户追加成功。
